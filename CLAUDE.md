## What this project is
A cross-platform (iOS + Android) mobile app that helps people in Norway feel —
and be — safer when walking home alone late in the evening.
All code is written by Claude Code. The project owner does not write code; the
owner reviews, answers questions and makes decisions.

## At the start of every session
1. Read `docs/plan/README.md`. The status table shows where we are.
2. Read `docs/plan/decisions.md`. Accepted decisions are binding unless the
   owner explicitly reopens them.
3. Open the section marked 🟡 or 🔵 and continue from its **Next steps**.
4. Follow the loop in `docs/plan/00-working-agreement.md`.
