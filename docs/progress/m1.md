### 2026-09-29 — M1 starts; SPIKE-01's spec is written (commit `27873bf`, branch `claude/busy-faraday-40n2zl`)

**The owner started M1 on 2026-09-29.** Two choices about how the work is done:
- the SPIKE-01 spec is written in a cloud session and reviewed as a docs-only
  pull request;
- the spike itself is built and run in a Mac session (D-055), as `claude-dev`
  (D-056). A cloud session has no simulator and no emulator.

**The spec** is [`specs/SPIKE-01.md`](../specs/SPIKE-01.md), committed as
`27873bf`. It has 16 acceptance criteria:
- **AC1–AC4, the setup:** the spike stands alone and is never shipped (AC1);
  debug builds run the pinned SDK on both platforms (AC2); the receiver
  measures on one clock and keeps no location (AC3); every route is synthetic
  (AC4).
- **AC5–AC11, S1–S7:** 45 minutes in the background with no gap over 2 minutes
  (AC5, S1); the reminder after a swipe (AC6, S2); stock Android's restrictions,
  with and without the battery exemption (AC7, S3); positions recorded offline
  arrive in order (AC8, S4); the alert on a silenced device (AC9, S5); one-tap
  calling written down (AC10, S6); reduced location permission detected within
  a minute (AC11, S7).
- **AC12–AC15, the rules and the go/no-go:** the SDK sends to our receiver and
  to no one else (AC12); every run counts (AC13); the results document (AC14);
  the recommendation follows the rule, and the owner decides (AC15).
- **AC16, S8:** MapLibre draws Kartverket's tiles on both devices.

**What the spec chooses.** These are for the owner's review of the pull
request, and all are in the spec's own words:
- **The receiver** is a throwaway `node:http` program on the Mac's loopback
  address, not staging and not `apps/server` run locally. It adds no product
  code, nothing leaves the Mac, and gaps are measured on one clock. It drops
  coordinates before anything is stored or printed.
- **The spike app** lives in `spikes/background-safety/app/`, outside the pnpm
  workspace, on Expo SDK 57 with its own lockfile. The root `package.json`,
  `pnpm-workspace.yaml` and `pnpm-lock.yaml` do not change, so the proprietary
  SDK never enters the root lockfile.
- **Debug builds with the JavaScript bundled in,** so a 45-minute run does not
  depend on Metro staying up.
- **Three verdict words:** passed, failed, and not shown on simulators. "Not
  shown" is never a pass and never a NO-GO. It is listed as open, with where it
  will be shown (L9, D-041).
- **The go/no-go rule** has seven items. S2, S5, S6 and S8 give findings for the
  owner and do not decide the SDK.
- **About 8 to 9 hours of Mac time,** one device at a time, preferably
  overnight.
- **CI is unchanged.** The spike's own tests run on the Mac, and the main
  session quotes their output in the pull request. `ai-review.yml` is not
  touched (D-075).

**The spec's one question, answered by the owner on 2026-09-29.** D-026 is
binding, and says Kartverket's terms and rate limits, and MapLibre's support for
its tile format, are verified "in the spike". But the roadmap's M1 row and the
S1–S7 table do not list it. The spec asked whether the spike also checks the
map, and recommended yes. **The owner chose (a): SPIKE-01 includes S8,** a check
of MapLibre with Kartverket's tiles at Galdhøpiggen, as D-026 asks.
- Galdhøpiggen is Norway's highest mountain. Nobody lives there and nobody walks
  home from it, so no made-up coordinates are needed and no person's place is
  shown.
- S8 does not count toward the location SDK's go/no-go. A failure is a finding
  for D-026, for the owner.
- The tiles come straight from Kartverket, because the tile proxy is later
  work. So the Mac's IP address reaches Kartverket, with no personal data.

**What the spec did not check.** It was written in a session with no simulator,
no emulator and no access to outside documentation. Every platform command in it
is marked "verify". Unverified until the Mac session:
- the SDK's current version, its support for Expo SDK 57 and the New
  Architecture, its licence text and its price;
- MapLibre's version, its licence and its New Architecture support;
- Kartverket's tile address, terms and rate limits.

The Mac session checks each and records what it found. A command that does not
exist changes how a criterion is shown, and never changes its pass condition.
It **stops and asks the owner** if the SDK's terms restrict evaluation in debug
builds, if the SDK sends data to its vendor, if the price is no longer $399, or
if Kartverket's terms forbid direct use from an app, need an account or a key,
or cost money. It also stops if the iOS toolchain fails: an Xcode below what Expo
SDK 57 needs (26.0.1 is this Mac's ceiling), no CocoaPods (installing it needs
the owner's admin account, D-056), or a simulator that will not boot in
`claude-dev`'s session.

**Where it stands.**
- The spec is committed. Its docs-only pull request is next.
- Nothing of the spike exists: `spikes/` holds only its README. No test is
  written, and no decision number is taken.
- The results will go in `docs/plan/04b-spike-results.md`, and the go/no-go is
  the owner's decision, because the $399 is a cost (D-023, D-031).
