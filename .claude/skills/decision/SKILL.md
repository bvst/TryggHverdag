# /decision $ARGUMENTS

Use the next free `D-` number. Fields: Date, Status (Accepted, or Accepted
(delegated, D-031)), Section, Context, Decision, Consequences. Never edit an
accepted decision: supersede it with a new one that links back, and mark the old
one "Superseded by D-xxx". Product scope, cost, privacy and safety decisions
need the owner's explicit answer first.
